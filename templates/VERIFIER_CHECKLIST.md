# Verifier Checklist — 独立replay検証器の検査項目

producer(通常実装)が出した確証格の数値を、独立実装(verifier)で再導出するときのチェックリスト。

## verifier実装の独立性

- [ ] verifierはproducerのモジュールを一切importしていない
- [ ] verifierは共有パーサ・共有ユーティリティを使っていない(標準ライブラリと外部汎用ライブラリのみ)
- [ ] verifierはproducerの中間生成物(パース済みCSV等)ではなく**生データ**(元のファイル・APIスナップショット)から再導出している
- [ ] verifierのdocstring/冒頭コメントに「producerを importしない」旨が明記されている
- [ ] 別コンテキストで実装した(エージェントに書かせる場合: producerの実装を見せず、仕様だけを渡した)

## 比較の規律

- [ ] 比較対象の統計量と許容誤差(TOL)が事前に決まっている
- [ ] 一致・不一致の結果が成果物(scorecard等)に機械的に記録される
- [ ] 不一致の場合、どちらが正しいか判明するまで両方の数値を引用禁止にしている
- [ ] 一致するまで、この数値は下流(意思決定・記事・レポート)に流していない

## 運用

- [ ] 適用対象は「確証格の数値」(投入判断・リリース・対外主張の根拠)に限定されている
- [ ] verifier自体の変更もレビュー対象(producerと同時に同じ人/エージェントが両方変更する場合は特に注意)
